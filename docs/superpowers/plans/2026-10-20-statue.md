# 雕像 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出普通怪「雕像」：前 3 个敌方回合蓄力，之后攻击 23、25、27……每次 +2；玩家本回合每打出一张牌，它受到的伤害 +20%（四舍五入），回合结束清零。

**Architecture:** 受伤加成用两个状态表示：被动「裂纹」`crack`（开战自带，出牌后给自己加层）和「受创」`cracked`（`turnEnd` 衰减，`modifyDamageTaken` 为 ×(1+0.2n)，带四舍五入标记）。递增攻击用 `EnemyDef.loopFrom`（意图走到末尾回到该下标）与攻击意图的 `grow` 字段（`EnemyState.attackBonus` 累计）。

**Tech Stack:** Vue 3 + TypeScript，vitest。

**Spec:** `docs/superpowers/specs/2026-10-20-statue-design.md`

## Global Constraints

- 引擎纯函数，战斗由种子决定；不引入随机。
- 80 生命；路线：idle ×3 → 攻击 23，之后每次攻击 +2，无上限。
- 每张牌 +20% 受伤，线性叠加（第 2 张 +20%，第 3 张 +40%），先结算牌再加层，回合结束清零，四舍五入。
- 药水不算"打出一张牌"；雕像死亡后不触发。
- 其他状态（易伤等）的取整行为不变（仍向下取整）。
- 不提交 git。

## Review Focus

- 第 1 张牌不吃加成，致命一击不加层（Task 1）。
- 回合结束加成清零，下回合从头算（Task 1）。
- 加成与易伤同时存在时取整结果正确，易伤单独存在仍向下取整（Task 1）。
- 蓄力 3 回合后第 4 回合打 23，之后 25、27，不回到蓄力（Task 2）。
- 意图显示的伤害含累计加成；动画期间的意图下标回退对 `loopFrom` 正确（Task 2）。
- 其他敌人的意图循环行为不变（Task 2）。
